# 用户端 uni-app

以手机 H5 为首期入口，桌面端居中显示，线上地址为 https://www.xiangzhen.site/。

- 游客浏览、搜索、分类与真实商家信息
- 独立账号注册登录，服务端会话验证，退出后令牌失效
- 商家菜单、售罄提示、起送门槛、换店确认与购物车
- 选择/新增/编辑收货地址，结算金额由后端报价
- 重复提交保护、15分钟未支付自动关闭、取消订单及库存恢复
- 订单筛选、进度刷新、商家与骑手电话联系
- 测试支付明确显示“不扣款”；正式支付尚未接入

```bash
npm ci
# 默认连接线上API；本地联调可覆盖：
VITE_API_BASE_URL=http://127.0.0.1:3000 npm run dev:h5
npm run type-check
npm run build:h5
```

默认开发端口5174。移除了共享开发用户ID，请在页面注册独立账号。账号为4–24位字母、数字或下划线，密码8–72位；昵称和电话不是登录凭证。

跑腿、收藏、优惠券、积分和评价暂不开放；页面不再展示虚构销量、评分、距离或满减。

跑腿入口已支持帮送、帮取、帮买。填写需求后等待运营报价，再确认报价并测试支付。跑腿订单在“订单 → 跑腿订单”与“我的 → 跑腿订单”查看；商品预算不在平台代收。
